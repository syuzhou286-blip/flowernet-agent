# Mathematics (Grade 8) · Marking Scheme (Points per Question, out of 100)

**Total 100 marks.** Multiple-choice and fill-in are marked right/wrong (full marks or 0, no negative marking). Calculation, equation, and word-problem questions are **marked by method**: award marks for correct steps even if the final answer is wrong.

## Section C — Calculation (8 marks each, by method)
**Q9** 3(2x − 1) + 2(x + 4)
- Expand first bracket (6x − 3): **2**
- Expand second bracket (2x + 8): **2**
- Collect like terms: **2**
- Correct answer 8x + 5: **2**

**Q10** (−2)³ + 4 × (−3) − (−5)
- (−2)³ = −8: **2**
- 4 × (−3) = −12: **2**
- Handle −(−5) = +5 correctly: **2**
- Correct answer −15: **2**

**Q11** (12 + 6 × 2) ÷ 6
- Multiply first (6 × 2 = 12): **2**
- Add inside bracket (24): **2**
- Divide (24 ÷ 6): **2**
- Correct answer 4: **2**

## Section D — Solve equation (8 marks each, by method)
**Q12** 3x − 5 = 16
- Add 5 to both sides: **2**
- 3x = 21: **2**
- Divide by 3: **2**
- x = 7 shown: **2**

**Q13** 2(x + 3) = 14
- Expand to 2x + 6 = 14: **2**
- Move constant (2x = 8): **2**
- Divide by 2: **2**
- x = 4: **2**

## Section E — Word problems (14 marks each, by method)
**Q14**
- Define the unknown (let book = $x): **4**
- Correct equation x + (x − 3) = 21: **4**
- Solve correctly (x = 12): **4**
- Answer with unit ("$12"): **2**

**Q15**
- Set up the equation (4n + 6 = 30): **4**
- Correct equation: **4**
- Solve correctly (n = 6): **4**
- State the answer: **2**

**Partial-credit rule (Section E):** if a student writes ONLY the final answer with no equation or working, award the "answer" marks only (2 for Q14, 2 for Q15) and withhold the method marks. Note this in the feedback so the teacher can override.

## Aggregation & grade boundaries
- **Total** = sum of all question marks (max 100).
- **Grade boundaries:** A ≥ 85, B ≥ 70, C ≥ 55, D ≥ 40, F < 40.
- **Pass mark:** 50.
