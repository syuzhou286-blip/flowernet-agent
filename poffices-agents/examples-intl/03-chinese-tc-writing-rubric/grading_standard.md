# 中國語文（中二）· 記敘文評分標準（分項分級）

本作文採用**分項分級評分**。共四個評分項，每項按 **優 / 良 / 合格 / 待改進** 四級評定；各項獨立評級，最後按總分得出整篇的綜合等級。

本題滿分 50 分，四項權重及對應分數區間如下。

---

## 項一：內容與立意（20 分）

| 等級 | 分數 | 描述 |
|---|---|---|
| 優 | 17–20 | 緊扣「嘗試／第一次」，選材真實新穎；中心突出，感情真摯；心理變化與成長感悟豐富。 |
| 良 | 13–16 | 切合題意，選材真實；中心明確；心理變化有所體現，但未夠深入。 |
| 合格 | 9–12 | 基本切題，但「嘗試」意味不足或選材普通；中心尚清楚，感悟較淺或點題生硬。 |
| 待改進 | 0–8 | 偏離題意（只寫一件事而無嘗試含義），或中心不明、無感悟；有失真或杜撰。 |

## 項二：結構與詳略（10 分）

| 等級 | 分數 | 描述 |
|---|---|---|
| 優 | 9–10 | 結構完整，層次分明；詳略得當，重點突出（嘗試過程詳寫）；首尾呼應，自然點題。 |
| 良 | 7–8 | 結構較完整，條理清楚；詳略大致得當；首尾有照應。 |
| 合格 | 5–6 | 有基本結構，但詳略不當或略嫌平均用力；段落尚清。 |
| 待改進 | 0–4 | 結構混亂或流水帳；無明顯詳略；段落不清。 |

## 項三：文句與表達（15 分）

| 等級 | 分數 | 描述 |
|---|---|---|
| 優 | 13–15 | 文句流暢生動，用詞準確；善用描寫（動作、心理、環境）；幾乎無語病。 |
| 良 | 10–12 | 文句通順，表達清楚；有一定描寫；偶有語病或用詞不當（兩處以內）。 |
| 合格 | 6–9 | 文句大致通順但平淡；描寫較少；語病較多（三至五處）。 |
| 待改進 | 0–5 | 文句不通，表達混亂；幾乎無描寫；語病甚多（五處以上）。 |

## 項四：錯別字與標點（5 分）

| 等級 | 分數 | 描述 |
|---|---|---|
| 優 | 5 | 書寫工整，卷面整潔，標點規範，無錯別字。 |
| 良 | 4 | 書寫較工整，標點大致規範，偶有錯別字（一至兩個）。 |
| 合格 | 3 | 書寫一般，錯別字或標點錯誤數處。 |
| 待改進 | 0–2 | 字跡潦草，錯別字與標點錯誤甚多。 |

---

## 綜合等級評定
1. 先分別評出四項的等級與分數。
2. 總分 = 四項分數之和（滿分 50）。
3. 綜合等級按總分對照下表：

| 綜合等級 | 總分 |
|---|---|
| 優 | 43–50 |
| 良 | 34–42 |
| 合格 | 25–33 |
| 待改進 | 0–24 |

## 特別扣分與規則
- **字數不足 600 字**：每少 50 字扣 1 分（最多扣 3 分）。
- **完全偏題**（無「嘗試」含義）：內容與立意一項直接評「待改進」，綜合等級不得高於「合格」。
- **出現真實校名／人名**：於「錯別字與標點」一項扣 1 分。
- **合格線**：綜合等級「合格」及以上（總分 ≥ 25）。
