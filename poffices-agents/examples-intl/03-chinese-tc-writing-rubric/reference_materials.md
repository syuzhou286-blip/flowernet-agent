# 中國語文（中二）· 記敘文寫作批改參考資料（資料庫）

## 一、作文題目
**題目：《一次難忘的嘗試》**

**寫作要求：**
1. 寫一篇記敘文，圍繞「嘗試」展開，寫出自己的真實經歷和感受。
2. 中心明確，條理清楚，詳略得當。
3. 全文不少於 600 字。
4. 文中不得出現真實的校名、人名。

## 二、批改所需知識（記敘文評價要點）

### 1. 記敘文六要素
時間、地點、人物、起因、經過、結果。當中「經過」是重點，應詳寫。

### 2. 本題審題要點
- 核心是「嘗試」：必須寫一件以前沒有做過、這次第一次去做的事，並寫出嘗試過程中的心理變化（猶豫／緊張 → 堅持 → 成功或收穫）。
- 「難忘」：要落在情感或成長上，結尾應有感悟、點題。
- 若只寫「做了一件事」而沒有「第一次嘗試」的意味，視為偏離題意。

### 3. 詳略得當的準則
- 應詳寫：嘗試過程中的關鍵動作、心理活動、困難與克服。
- 應略寫：背景交代、次要人物、事後議論。
- 通篇平均用力、流水帳，屬於詳略不當。

### 4. 常見毛病（用以辨識學生失誤）
- 偏題：寫成一件事，卻無「嘗試／第一次」的含義。
- 流水帳：按時間順序羅列，缺乏詳略與重點。
- 中心不明：結尾沒有點題、沒有感悟。
- 心理描寫欠缺：只寫做了甚麼，沒有寫想了甚麼、怕甚麼。
- 首尾脫節：結尾感悟與開頭或中心無關。

## 三、範文（比對參考）

**一次難忘的嘗試**

我自小怕水，連泳池的淺水區也不敢下去。可是那年暑假，我第一次嘗試獨自游到對岸。

站在池邊，我的腿有點發軟。水面在陽光下閃動，彷彿在嘲笑我的膽怯。教練在對岸向我招手，我卻遲遲不敢邁步。「不如算了吧？」這個念頭一次又一次冒出來。可是想到同伴一個個都游了過去，我咬一咬牙，深吸一口氣，縱身跳進水裏。

冰涼的水一下子把我包住，我手忙腳亂地划着，嗆了好幾口水。中途我幾乎撐不住，腦海裏只剩下一個念頭：站起來吧。可是腳一沉，我又想起教練說的「放鬆，手腳配合」。我強迫自己慢下來，一下、又一下，笨拙卻固執地朝對岸靠近。

當我的手終於摸到對岸池壁時，我大口喘着氣，卻忍不住笑了。原來我怕的從來不是水，而是那個不敢開始的自己。

那一次嘗試讓我明白：很多事情，只有跳下去，才知道自己能游多遠。

（約 600 字，此處為節錄示意。）

## 四、格式與規範
- 本次寫作為記敘文，第一人稱敘述。
- 卷面應整潔，標點規範，段落分明（一般不少於四段）。
