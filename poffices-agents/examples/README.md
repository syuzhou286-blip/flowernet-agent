# 测试用例 · 三份作业（语 / 数 / 英）

用于在真实平台上验证两个 Agent 的效果。三份用例的**评分结构各不相同**，正好覆盖 Grader 的三种打分模式。

| 用例 | 学科 | 评分标准类型 | 触发的 Grader 模式 | KB 里的 `standard_type` |
|---|---|---|---|---|
| 01 | 语文作文 | 分项分级（优/良/合格/待提高，开放性） | MODE A（维度评分） | `rubric_matrix` |
| 02 | 数学 | 百分制、按题分步给分 | MODE B（逐题给分） | `points_per_item` |
| 03 | 英语 | A/B/C/D 整体等级 | MODE C（等级判定） | `grade_bands` |

## 怎么跑

**第 1 步 · Agent 1（Knowledge Base Builder, 359）**
每个用例目录里上传两份文件：
1. `参考资料.md`（批改所需的数据库：题目、范文/标准答案、批改要点）
2. `评分标准.md`（评分标准：rubric / 给分细则 / 等级描述）

跑完看输出 **Part 1 第一行**：应显示 `✅ Grading standard included — type: ...`。若显示 `❌ GRADING STANDARD MISSING` 说明没抓到评分标准，需要检查。复制 **Part 2 的 JSON**。

**第 2 步 · Agent 2（Worksheet Grader, 360）**
把上一步的 JSON 贴进 **Image Rules** 变量，上传该用例的 `学生作业.md`，跑批改。

**额外测试（缺失评分标准的兜底）**：Agent 1 只上传 `参考资料.md`、不传 `评分标准.md`，应看到 `❌ GRADING STANDARD MISSING`；把这份 KB 交给 Agent 2，应**拒绝出分**并提示补传，而不是自己编一套分数。

## 每份作业里埋的典型问题（对照 Grader 输出检查）

### 01 语文作文（学生A）——预期综合等级：合格 或 待提高
- **偏题**：题目要求写"尝试/第一次"，学生写成"去公园玩的一天"，只有"划船"一小段沾边 →「内容与立意」应判**待提高或合格**，并按规则综合等级不得过高。
- **记流水账**：按时间罗列（早上→中午→下午→回家），无详略 →「条理与结构」应扣。
- **无感悟/点题弱**：结尾只是"很开心、很难忘" →「内容」偏弱。
- **心理描写缺失**、语言平淡、夹用英文单词 "food" →「语言与表达」应扣，且属规范问题。
- **字数不足 600**（约 300 字）→ 应触发字数扣分规则。
- ✅ 验证点：Grader 是否用了**优/良/合格/待提高**这套等级（而不是默认的 1–5 分），是否逐维度对照了 rubric 描述，最后是否按总分区间给出综合等级。

### 02 数学（学生B）——预期总分约 55–60，等级"待及格/合格"边缘
逐题预期（对照评分细则的分步给分）：
- 1. A ✓ 4/4；2. D ✗ 0/4（应 A）；3. B ✓ 4/4；4. A ✗ 0/4（应 C，漏负值）
- 5. -2 ✓ 4/4；6. `<` ✗ 0/4（应 >）；7. 2 ✓ 4/4；8. 只写"7" → **2/4**（漏 -7，部分分）
- 9. 幂对/乘法对，但"-(-6)"当成"-6"符号错、结果错 → **约 4/8**（前两步得分）
- 10. 空白 → 0/8
- 11. 去括号有一处符号错（-2×-3b 写成 -6b），合并与其展开一致 → **约 4/8**（去括号部分分 + 合并分）
- 12. 移项对、合并对，但 `-3x=9` 解成 `x=3` 符号错 → **约 4–6/8**（末步系数化 0 分）
- 13. 空白 → 0/8
- 14. 完整正确（设/列/解/答齐全）→ **14/14**（一道满分题，验证强答案不被误扣）
- 15. **只写"成本价是 300 元"，答案对但无任何过程** → 按细则"只有答案最多给 2 分" → **2/14**
- ✅ 验证点：Grader 是否**逐题分步给分**（不是整题对错）、第 9/11/12 题是否给了**部分分**、第 15 题"答案对但没过程"是否按埋进 Prompt 的规则只给答案分并提示老师可复核、总分是否按 100 制并换算等级。

### 03 英语（学生C）——预期等级：C 档
- **内容基本齐全**但第三点（邀请）表达生硬、发挥少。
- **语言错误多**（6–8 处）：`You ask`（应 asked/ask 时态）、`On weekend`（应 On weekends）、`My friend play`（三单 plays）、`it make`（makes）、`is play football`（is playing / to play）、`many place`（places）、`This summer you come`（缺情态/邀请句式）。
- **格式**基本完整（有 Dear / Yours）。
- ✅ 验证点：Grader 是否用 **A/B/C/D 等级**（不是分数）、是否**从低档往上对照选"完全满足的最高档"**、是否引用了 C 档描述作依据、是否给出**是否达到合格线（C 及以上）**的判断。

## 说明
- 这些学生作业**故意做成中等偏弱**，方便看 Grader 会不会如实指出问题、会不会过度表扬。
- 三份评分标准刻意用了三种不同的量表（等级词 / 百分制 / 字母档），用来验证 Grader **不写死、按 KB 里的标准动态打分**。
- 若某一模式输出不符合预期，把该用例的 KB JSON 和 Grader 输出发我，可据此再调 Prompt。
