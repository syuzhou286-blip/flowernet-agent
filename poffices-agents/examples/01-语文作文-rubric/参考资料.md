# 七年级语文 · 作文批改参考资料（数据库）

## 一、作文题目
**题目：《一次难忘的尝试》**

**写作要求：**
1. 写一篇记叙文，围绕"尝试"展开，写出自己的真实经历和感受。
2. 中心明确，条理清楚，详略得当。
3. 不少于 600 字。
4. 文中不得出现真实的校名、人名。

## 二、批改所需知识与要点（记叙文评价维度）

### 1. 记叙文六要素
时间、地点、人物、起因、经过、结果。经过是重点，应详写。

### 2. 本题审题要点
- 核心是"尝试"：必须写一件"以前没做过、这次第一次去做"的事，并写出尝试过程中的心理变化（犹豫/紧张 → 坚持 → 成功或收获）。
- "难忘"：要落到情感或成长上，结尾应有感悟、点题。
- 只写"做了一件事"而没有"第一次尝试"的意味，视为偏题。

### 3. 详略得当的标准
- 应详写：尝试过程中的关键动作、心理活动、困难与克服。
- 应略写：背景交代、次要人物、事后议论。
- 通篇平均用力、流水账，属于详略不当。

### 4. 常见问题清单（用于识别学生典型失误）
- 偏题：写成"一件事"但没有"尝试/第一次"的含义。
- 记流水账：按时间罗列，缺乏详略与重点。
- 中心不明：结尾没有点题、没有感悟。
- 心理描写缺失：只写做了什么，没写想了什么、怕什么。
- 开头结尾脱节：结尾感悟与开头/中心无关。

## 三、范文（模型答案，供比对参考）

**一次难忘的尝试**

我从小怕水，连游泳池的浅水区都不敢下。可那年暑假，我第一次尝试独自游到对岸。

站在泳池边，我的腿有些发软。水面在阳光下晃着，像是在嘲笑我的胆怯。教练在对岸朝我招手，我却迟迟不敢迈步。"要不算了吧？"这个念头一次次冒出来。可想到同伴们一个个都游了过去，我咬了咬牙，深吸一口气，纵身跳进了水里。

冰凉的水一下子把我包住，我手忙脚乱地划着，呛了好几口水。中途我几乎撑不住了，脑子里只剩下一个念头：站起来吧。可脚一沉，我又想起教练说的"放松，手脚配合"。我强迫自己慢下来，一下、又一下，笨拙却固执地朝对岸靠近。

当我的手终于摸到对岸池壁时，我大口喘着气，却忍不住笑了。原来我怕的从来不是水，而是那个不敢开始的自己。

那一次尝试让我明白：很多事情，只有跳下去，才知道自己能游到多远。

（约 620 字节选，实际范文完整）

- 卷面应整洁，标点规范，段落分明（一般不少于 4 段）。
