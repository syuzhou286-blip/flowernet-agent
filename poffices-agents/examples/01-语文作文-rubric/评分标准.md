# 七年级语文 · 作文评分标准（分项分级 · 开放性）

本作文采用**分项分级评分**。共四个评价维度，每个维度按 **优秀 / 良好 / 合格 / 待提高** 四档评定。各维度独立评级，最后综合得出整篇作文的总等级。

满分参考：本题满分 50 分，四项权重如下（既给等级，也给对应分数区间，便于折算）。

---

## 维度一：内容与立意（20 分，权重最高）

| 等级 | 分数区间 | 描述 |
|---|---|---|
| 优秀 | 17–20 | 紧扣"尝试/第一次"，选材新颖真实；中心突出，有真情实感；有明确的心理变化与成长感悟。 |
| 良好 | 13–16 | 切合题意，选材真实；中心明确，情感较真实；心理变化有所体现但不够深入。 |
| 合格 | 9–12 | 基本符合题意，但"尝试"意味不足或选材普通；中心尚清楚，感悟较浅或点题生硬。 |
| 待提高 | 0–8 | 偏离题意（只写"一件事"无尝试含义），或中心不明、无感悟；有胡编、失真现象。 |

## 维度二：条理与结构（10 分）

| 等级 | 分数区间 | 描述 |
|---|---|---|
| 优秀 | 9–10 | 结构完整，层次分明；详略得当，重点突出（尝试过程详写）；首尾呼应、自然点题。 |
| 良好 | 7–8 | 结构较完整，条理清楚；详略基本得当；首尾有照应。 |
| 合格 | 5–6 | 有基本结构，但详略不当或略显平均用力；段落划分尚可。 |
| 待提高 | 0–4 | 结构混乱或记流水账；无明显详略；段落不清。 |

## 维度三：语言与表达（15 分）

| 等级 | 分数区间 | 描述 |
|---|---|---|
| 优秀 | 13–15 | 语言流畅生动，用词准确；能恰当运用描写（动作、心理、环境）；基本无语病。 |
| 良好 | 10–12 | 语言通顺，表达清楚；有一定描写；偶有语病或用词不当（2 处以内）。 |
| 合格 | 6–9 | 语言基本通顺，但平淡；描写较少；语病较多（3–5 处）。 |
| 待提高 | 0–5 | 语句不通，表达混乱；几乎无描写；语病多（5 处以上）。 |

## 维度四：书写与卷面（5 分）

| 等级 | 分数区间 | 描述 |
|---|---|---|
| 优秀 | 5 | 书写工整，卷面整洁，标点规范。 |
| 良好 | 4 | 书写较工整，标点基本规范，个别涂改。 |
| 合格 | 3 | 书写一般，有涂改，标点偶有错误。 |
| 待提高 | 0–2 | 字迹潦草，卷面凌乱，标点错误多。 |

---

## 综合等级评定规则（overall aggregation）

1. 先分别给出四个维度的等级与分数。
2. 总分 = 四个维度分数之和（满分 50）。
3. 综合等级由总分对照下表得出：

| 综合等级 | 总分区间 |
|---|---|
| 优秀 | 43–50 |
| 良好 | 34–42 |
| 合格 | 25–33 |
| 待提高 | 0–24 |

## 特别扣分与规则
- **字数不足 600 字**：每少 50 字，从总分中扣 1 分（最多扣 3 分）。
- **完全偏题**（无"尝试"含义）：内容与立意维度直接判"待提高"，综合等级不得高于"合格"。
- **出现真实校名/人名**：从卷面维度扣 1 分。
- 合格线为综合等级"合格"及以上（总分 ≥ 25）。
