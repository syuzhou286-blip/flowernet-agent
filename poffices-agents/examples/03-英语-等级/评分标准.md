# 八年级英语 · 书面表达评分标准（整体等级制 A / B / C / D）

本题采用**整体评分（holistic）**，按作文整体印象评定一个等级：**A / B / C / D**。评定时综合考虑三方面：**内容要点、语言准确性、行文连贯与格式**，不单独逐项打分，而是对照下列各档描述，选取最贴合的整体档次。

---

## 等级档次描述（band descriptors）

### A 档（优秀）
- **内容：** 三个要点全部覆盖且有适当发挥，信息充实。
- **语言：** 语法与拼写基本准确，仅有个别小错（1–2 处），不影响理解；能使用多样的句式与词汇。
- **连贯与格式：** 行文连贯，使用了恰当的连接词；邮件格式完整（称呼、正文、落款齐全）。
- **总体印象：** 达到或接近范文水平。

### B 档（良好）
- **内容：** 覆盖三个要点，个别要点展开略简单。
- **语言：** 有一些语法或拼写错误（3–5 处），但基本不影响理解；句式以简单句为主，偶有复合句。
- **连贯与格式：** 行文较连贯；邮件格式基本完整（可能缺落款或称呼之一）。
- **总体印象：** 表达清楚，能完成交际任务。

### C 档（合格）
- **内容：** 遗漏一个要点，或要点表达不清楚。
- **语言：** 错误较多（6–8 处），部分句子影响理解；词汇与句式单一，有中式英语。
- **连贯与格式：** 行文欠连贯，句子间较松散；格式不完整。
- **总体印象：** 勉强传达主要意思。

### D 档（待提高）
- **内容：** 遗漏两个及以上要点，或严重偏题。
- **语言：** 错误很多（8 处以上），多数句子难以理解；词汇匮乏。
- **连贯与格式：** 几乎无连贯性；无邮件格式。
- **总体印象：** 难以完成交际任务。

---

## 评定规则（aggregation）
1. 通读全文，形成整体印象。
2. 从 D 档往上对照，找出学生作文**能够完全满足其描述的最高档次**，即为最终等级。
3. 若介于两档之间，看其**最薄弱的一项**（内容 / 语言 / 连贯）落在哪一档，就近取较低档。
4. **合格线：C 档及以上**（A、B、C 为通过，D 为不通过）。
5. 附加说明：明显抄袭范文原句、或字数严重不足（< 40 词）者，最高不超过 C 档。
